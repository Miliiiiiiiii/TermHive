# TermHive 路线图

> 对标 Xshell / Xftp / MobaXterm / FinalShell / Termius / Tabby / WindTerm / WinSCP 等主流远程工具的差距分析与功能规划。立项规则见 [VERSIONING.md](VERSIONING.md):一个 MINOR 版本 = 一个规划好的功能批次。

## 当前能力(0.1.0)

| 能力域 | 已具备 |
|---|---|
| 连接体系 | DBX 原生 connection-provider;密码/私钥/键盘交互认证、认证方式智能回退、用户名密码防呆;keepalive、GBK/GB18030 编码、连接超时与登录后命令 |
| 安全 | 服务器指纹校验(TOFU,known_hosts.json);重连凭据密封落盘(Windows DPAPI / AES-256-GCM),明文只在内存 |
| 终端 | 每会话独立 xterm;WebGL 渲染(自动降级)、Ctrl+F 搜索、链接可点、输出微批合帧;断线"重新连接"覆盖层 + 128KB 回放;浮窗迷你终端 |
| 多会话与分组 | 同一连接任意多会话(共享一条 SSH 连接);标签名持久、双击重命名;会话分组(≤4 栏自动分栏、跨服务器同组、组名可改可解散) |
| 文件管理 | SFTP 浏览/上传/下载/重命名/删除/新建文件夹;拖拽上传(含文件夹递归);多选批量下载(zip 流式打包);文件面板跟随终端 cwd(OSC 7,会话级开关) |
| 日志场景 | 文件面板一键 tail -f 跟随(xterm 渲染 + 着色规则联动 + Ctrl+F 搜索 + 滚动锁定 + 轮转重置);会话日志带时间戳落盘(按连接分目录,设置开关);断线自动重连(指数退避 2s→60s,可关,认证/指纹失败即弃) |
| 远程编辑 | 连接编码自动转码;≤2MB 全量可编辑,超过分段只读浏览(导航 + 一键下载);二进制识别;临时文件 + 原子替换保存(Ctrl+S) |
| 传输引擎 | 大文件下载并发分块读(按序重组);下载缓冲池化;SFTP 通道断线自愈 |
| AI 工具(MCP) | 12 个工具三档对外授权(read / write / full);白名单命令分类器、只读日志跟随三件套(tail_start/tail_read/tail_stop)、灾难模式硬拒、写操作逐次弹窗批准、SFTP 路径护栏、命令超时与输出上限、调用进 diag.log 与 DBX 审计 |
| 设置 | 配色主题(One Dark / Dracula / Solarized Dark / Nord / GitHub Light / 跟随 DBX);日志着色规则(正则 + 调色盘/色轮任意色,整行/片段);终端字体/字号/回滚;行为开关(重连上限/会话日志/传输自动关闭/禁用注入);插件级实时广播 |
| 增强能力 | 快速命令栏;工作区一键恢复;分组广播输入;rz/sz(ZMODEM);服务器监控薄版;日志查看器实时过滤;远程编辑器语法高亮(CodeMirror 6);文件面板隐藏文件/排序/收藏 |
| 诊断 | 飞行记录仪:全量 UI↔后端调用写 diag.log(自动脱敏、封顶 128KiB) |
| 工程 | proto / e2e / PTY 模式测试套件(内嵌 SSH+SFTP 测试服务器);CI 门禁(版本一致性 + CHANGELOG 覆盖 + 类型检查 + 构建断言 + 全量测试);发版脚本 + GitHub Actions 自动打包 .dbxp |

## 对标差距分析

| 工具 | 核心特色 | 借鉴点 |
|---|---|---|
| Xshell | 会话管理成熟、隧道管理、快速命令栏、宏、会话日志录制 | 快速命令栏;会话日志带时间戳落盘 |
| Xftp | 双窗格本地↔远端同步浏览、远端文件编辑、"保持远程目录最新" | 双面板对比同步(P3) |
| MobaXterm | 多协议全家桶、内嵌 SFTP 跟随终端 cwd、宏录制 | 宏录制后期考虑 |
| FinalShell | 服务器监控仪表盘(CPU/内存/网络曲线)、进程管理、GPU 监控 | 监控面板 + 进程管理,用户感知最强,建议尽早 |
| Termius | 跨端同步、密钥管理、代码片段库、端口转发管理 UI | 密钥生成器;片段库;端口转发管理 |
| Tabby | 插件生态、主题丰富、分屏、快捷键体系 | 快捷键可配置 |
| WindTerm | 极致性能、命令面板(Ctrl+Shift+P) | 命令面板 |
| WinSCP | 断点续传、传输校验、目录同步 | 传输队列续传/重试/校验;同步浏览 |
| SecureCRT | 日志选项极细(时间戳、按连接分流) | 会话日志带时间戳、按连接分目录 |

**结论**:当前 ≈ "Xshell 基础终端 + Xftp 基础文件面板 + AI 工具差异化"。差距最大、用户感知最强的三块:**日志/监控场景**、**文件能力纵深**、**传输体验**。

2. 文件操作纵深:chmod 权限 UI、远端压缩/解压(zip/tar.gz 一键)、面板内搜索;(隐藏文件开关、列排序、收藏路径已于 2026-11-06 落地)
3. 多文件并行传输(限并发防占满带宽);(单文件的并发分块管道已于 2026-11-06 落地)
4. 免下载预览扩展:图片 / HEX / 压缩包内列表浏览
5. ~~快速命令/代码片段栏~~(2026-11-06 落地;占位变量仍是候选)

## P2 — 监控与运维(0.4 主题)

1. **监控仪表盘**(FinalShell 式):CPU/内存/磁盘薄版已于 2026-11-06 落地;待深化:网络曲线、进程列表/kill、GPU 卡片(nvidia-smi)

4. ~~多会话广播输入~~(2026-11-06 落地,按分组广播)
5. 密钥生成器(ssh-keygen 图形化)、known_hosts 管理 UI

## P3 — 平台化与差异化(1.0 前景)

- 命令面板 + 自定义快捷键;字体/字号/回滚行数/复制粘贴规则设置
- 连接导入:Xshell(.xml)/ PuTTY(reg)——迁移**连接结构**(主机/端口/用户名/认证方式/私钥路径,私钥认证的连接导入即用);**密码不迁移**(Xshell 加密存储无法正经解出、PuTTY 本就不存),密码认证的连接首次连接时补输一次即入 secret-store
- 双面板本地↔远端同步浏览(WinSCP "keep remote up to date")
- 回放瘦身:**平台限制搁置**——xterm.js 没有"向 scrollback 顶部插入历史"的 API,按需前拉在架构上不可实现,纯砍头(只留尾部 N 屏)等于把现有 128KB≈60 屏历史砍成个位数屏,是功能倒退;待 xterm 能力变化再评估。diag.log 结构化(JSON 行 + 级别过滤)不受影响仍为候选
- mosh(弱网漫游);跨平台构建矩阵(macOS/Linux);自动更新检查
- AI 辅助深化(报错解释/命令生成,与 DBX 数据库场景契合的差异化卖点)

## 明确不做(范围控制)

- X11 转发、RDP/VNC、FTP 协议(文件管理走 SSH+SFTP)
- 多标签页管理(宿主 DBX 已管,插件做内部会话标签)
- 插件生态/脚本市场(超出单人项目体量)

## 平台约束备忘(做功能前先看)

| 约束 | 影响 |
|---|---|
| UI 桥二进制帧上限 8MiB / sidecar 64MiB | 预览、传输必须分块+确认;禁止单个大 JSON |
| storage 单值 256KiB / 库 1MiB | 规则集、片段库够用;主题 JSON 注意体积 |
| floating 每 contribution 仅一个 | 浮窗内做会话切换,不能开第二个浮窗 |
| fileTransfer 文件夹展开上限 2000 文件 / 8 层 | 大目录树上传有上限 |
| 宿主不感知网络层断开(绿点常亮) | 断线状态以 UI 的 shell.closed 为准,勿当宿主 bug 排查 |
